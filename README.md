# Five Little Monkeys

Five monkeys bounce on one giant bed. Slam the mattress and the ring of quilt launches the others off. Last monkey
jumping wins. Up to five players; bots fill the empty seats.

Play: https://onceworlds.com/play/five-little-monkeys

- `npm install`, then `npm run build` (Vite, into `dist/`).
- `npm test`: the physics, rings, bots and round rules, balance simulations, message checks, and whole matches through a
  fake room.
- `?poster=cover|action|win|multi|icon|badge-<id>` draws the store art.

How it plays, the numbers and the netcode: [DESIGN.md](DESIGN.md).
